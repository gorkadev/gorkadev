### Hi, I'm Gorka

Frontend developer in Pamplona, Spain. I work at Nubapp on the admin panel of a
sports-management SaaS — React, TypeScript, and the design system underneath it.

Most of my time lately goes into AI tooling for my team: MCP servers, skills,

exists instead of the code they imagine.

beside it to keep changing it. It's where most of my time has gone these last
few weeks. Next.js, three.js, and Trigger.dev for the agent runs.

- **[flight-deck](https://github.com/gorkadev/flight-deck)** — instruments for

- **[devdeck](https://github.com/gorkadev/devdeck)** — the developer tools you
  keep googling: JWT, JSON, cron, hashes, UUIDs. Runs entirely in the browser,
  nothing is uploaded.
- **[cv](https://github.com/gorkadev/cv)** — my résumé as a repo. One A4 page,
  exported to PDF with headless Chrome, and the build fails if it overflows.
